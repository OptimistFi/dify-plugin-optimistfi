# OptimistFi

覆盖 40 多家交易场所的永续合约数据、加密自营交易公司（prop firm）信息，以及美国上市公司披露，作为 Dify 智能体和工作流的工具使用。无需 API 密钥。

**作者：** [OptimistFi](https://optimistfi.com) · **源代码：** [github.com/OptimistFi/dify-plugin-optimistfi](https://github.com/OptimistFi/dify-plugin-optimistfi) · **联系：** hello@optimistfi.com

## 概述

OptimistFi 每小时读取各大永续合约交易场所的数据，收集为加密货币和股票永续合约交易者提供资金的自营交易公司的规则与价格，并读取 SEC EDGAR 和美国众议院书记官处的公司披露。本插件把这些数据作为八个工具提供给 Dify。

## 配置

无需任何配置：没有 API 密钥、凭证或授权步骤。从 Dify 插件市场安装 **OptimistFi** 后，八个工具即可在智能体、Chatflow 和 Workflow 中使用。插件通过 HTTPS 连接 `https://mcp.optimistfi.com/mcp`，自托管的 Dify 需要能访问该地址。

## 工具

| 工具 | 内容 |
|---|---|
| **永续合约行情** | 单个市场在所有交易场所的实时数据：价格、未平仓量、资金费率、杠杆、清算价位、最大成交和大户持仓。 |
| **永续合约历史** | 单个市场 1、7、30 或 90 天的走势：价格、未平仓量、资金费率、主动买卖和 Hyperliquid 千万美元以上账户的净持仓。 |
| **永续合约筛选器** | 20 个排名视图：未平仓量增长、涨跌幅、资金费率极值与跨所价差、清算、清算最大痛点、10 万美元以上大额成交、百万美元以上账户多空、现货 ETF 资金流、期权、期货基差、恐惧与贪婪指数、板块等。 |
| **自营交易公司** | 规则、每个挑战的价格（含通过后需支付的激活费）、当前折扣码、所在国家和最高资金额度，取自各公司官网。 |
| **内部人交易** | 来自 SEC EDGAR 的 Form 4 申报，给出交易日期和公开日期。 |
| **国会议员交易** | 依据《STOCK 法案》的美国众议院股票披露，可按代码或议员查询，附申报文件链接。 |
| **SEC 文件** | 8-K 事件、财报新闻稿、8-K 正文和治理风险信号。 |
| **财报日历** | 根据公司自身申报规律推算的下一次财报日期，标注为估计并给出依据。 |

## 在工作流中的输出

每个工具节点返回 `text`（带单位、数据时间和来源链接的 Markdown 摘要）、`json`（完整记录）、类型化变量，以及在没有数据时设置的 `error`。永续合约工具还返回 `chart`：在 Answer 节点中插入工具节点的 `chart` 变量，Dify 即可绘制图表。“返回内容”设置可选择仅返回摘要，以减少智能体的上下文。

## 关于数据

每个回答都附有读取时间和来源：各交易场所的公开市场数据、SEC EDGAR 或美国众议院书记官处。未读取到的数据会明确说明，而不是返回空列表；推算的未来日期标注为估计。

## 隐私

插件只把各工具的输入（代码、公司名称、视图）发送给 OptimistFi，不收集个人数据，也不存储任何内容。详见 [PRIVACY.md](../PRIVACY.md)。
