# OptimistFi

美国上市公司披露数据，作为 Dify 智能体和工作流的工具使用：SEC Form 4 内部人交易、美国众议院议员的股票交易、SEC EDGAR 的 8-K 事件与风险信号检查，以及预计财报日期。无需 API 密钥。

## 概述

OptimistFi 读取 SEC EDGAR 的公司申报和美国众议院书记官处的股票交易披露，并为每笔交易标注两个日期：交易发生日和申报公开日。本插件把这些数据作为四个工具提供给 Dify。

## 配置

无需任何配置：没有 API 密钥、凭证或授权步骤。从 Dify 插件市场安装 **OptimistFi** 后，四个工具即可在智能体、Chatflow 和 Workflow 中使用。插件通过 HTTPS 连接 `https://mcp.optimistfi.com/mcp`，自托管的 Dify 需要能访问该地址。

## 工具

| 工具 | 内容 |
|---|---|
| **内部人交易** | 来自 SEC EDGAR 的美国公司 Form 4 申报：人员、职位、交易代码、股数和金额，并给出交易日期和公开日期。公开市场买卖排在前面，其后是授予、期权行权和赠与。 |
| **国会议员交易** | 依据《STOCK 法案》的美国众议院股票披露，可按代码或议员查询。按代码查询时先给出买入、卖出和最活跃的议员；每条注明交易所在的账户，并附申报文件链接。 |
| **SEC 文件** | 8-K 事件、财报新闻稿、近期 8-K 正文和治理风险信号（延迟申报、更换审计师、内部人集中卖出）。 |
| **财报日历** | 根据公司自身申报规律推算的下一次财报日期，标注为估计并给出依据；有临床试验的公司还列出试验结果日期。 |

## 使用场景

- **内部人与国会交易监控：** 定时 Workflow 读取关注列表的内部人交易和国会议员交易，把新申报发送到 Slack 或邮件。
- **财报周准备：** 智能体列出本周发布财报的公司，并调出每家公司近期的 8-K 事件和风险信号检查。
- **尽职调查智能体：** 一个配备四个工具的智能体可以回答“Moderna 本季度有人卖出股票吗”“哪些众议员买入了 NVDA”“这家公司更换过审计师吗”。

## 在工作流中的输出

每个工具节点返回 `text`（带单位、数据时间和来源链接的 Markdown 摘要）、`json`（完整记录）、类型化变量（如 `company`、`count`、`acquired_usd`、`lean`、`next_earnings`），以及在没有数据时设置的 `error`。“返回内容”设置可选择仅返回摘要，以减少智能体的上下文。

## 关于数据

每个回答都附有读取时间和来源：SEC EDGAR 或美国众议院书记官处。每笔交易同时给出发生日期和公开日期。未读取到的数据会明确说明，而不是返回空列表；推算的未来日期标注为估计。

## 隐私

插件只把各工具的输入（股票代码或公司名称、众议员姓名、申报类型）发送给 OptimistFi，不收集个人数据，也不存储任何内容。详见 [PRIVACY.md](../PRIVACY.md)。
